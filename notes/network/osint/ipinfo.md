## 概要

`https://ipinfo.io/<IP>` にアクセスすると、その IP アドレスの推定位置（国・地域・都市・緯度経度）と、割り当て先の組織（AS 番号とプロバイダー名）が分かる。ログに残っている接続元の IP アドレスが、どの国のどんな回線（家庭用のプロバイダーか、クラウド事業者か）からのものかを調べるときに使う。

## コマンド

```
$ curl https://ipinfo.io/203.0.113.10
{
  "ip": "203.0.113.10",
  "city": "...",
  "region": "...",
  "country": "JP",
  "loc": "35.xxxx,139.xxxx",
  "org": "AS64500 Example ISP",
  ...
}
```

ブラウザで `https://ipinfo.io/<IP>` を開いても同じ情報が見られる。

## 注意点

- IP アドレスから分かる位置は、プロバイダーの設備や登録情報からの推定で、住所が分かるわけではない。都市単位でも外れることがあり、モバイル回線では離れた都市として出ることも多い。
- VPN、Tor、クラウドのサーバーを経由した接続では、出てくるのは経由先の位置。`org` がクラウド事業者やホスティング事業者なら、利用者の実際の場所ではないと考える。
