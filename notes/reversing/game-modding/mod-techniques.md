## 手法の一覧

上から順に安全で手軽、下に行くほど強力だが壊れやすく、利用規約にも触れやすい。

| 手法 | 仕組み | 例 |
|---|---|---|
| 1. 公式の Mod 対応 | ゲームに最初から Mod を読み込む機能がある。決められた場所にファイルを置くだけで動く | Steam ワークショップ、Minecraft のリソースパック |
| 2. ファイルの置き換え | 画像・音・テキストなどのデータファイルを差し替える。プログラムには触らない | テクスチャ Mod、翻訳ファイルの差し替え |
| 3. 起動方法の変更（Mod ローダー） | ゲーム本体より先にローダーを起動し、ローダーにゲームを読み込ませる。読み込みのタイミングでゲームのプログラムを書き換える | Fabric、Forge（Minecraft Java 版） |
| 4. DLL ハイジャック | ゲームが起動時に読み込む DLL と同じ名前のファイルを `.exe` の隣に置いて横取りし、そこから Mod を起動してゲームの関数に割り込む | BepInEx、ReShade、MelonLoader |
| 5. DLL インジェクション | 動いているゲームのプロセスに、外部のツールから DLL を押し込む | 一部のオーバーレイツール、チートツール |
| 6. 実行ファイルの書き換え | `.exe` や DLL そのものを改造して保存する | 古いゲームの非公式パッチ |

## 補足

- 4 は、攻撃手法の DLL Hijacking（「DLL Hijacking（検索順序を利用した悪意ある DLL の読み込み）」のノート）と同じ仕組み。Windows は DLL を実行ファイルと同じフォルダーから先に探すので、そこに同名の DLL を置くと本物より先に読み込まれる。Mod ローダーは、横取りした DLL の中で本物の DLL の関数も呼び出して（プロキシして）、ゲームが普段どおり動くようにしている。
- 3〜6 はゲームのプログラムに手を入れるので、ゲームが更新されると関数の位置や構造が変わって動かなくなりやすい。6 はファイルそのものを書き換えるため、特に壊れやすい。
- オンラインゲームでは、4〜6 はアンチチートに検知されてアカウント停止の対象になることがある。
