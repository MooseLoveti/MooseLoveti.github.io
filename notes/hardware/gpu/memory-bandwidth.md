## 概要

メモリ帯域は、GPU が VRAM と 1 秒間にやり取りできるデータ量。LLM の推論のように、計算よりもメモリからの読み出しが律速になる処理では、コア数より帯域が効く。

帯域は、メモリバス幅（一度にやり取りできるビット数）と VRAM の速度（1 ピンあたりの転送レート）の掛け算で決まる。

```
帯域（GB/s）≒ バス幅（bit）÷ 8 × 転送レート（Gbps）
例: 384bit ÷ 8 × 21Gbps = 1,008GB/s（RTX 4090）
```

## メモリ帯域の目安

| 帯域 | 評価 | 代表的な GPU |
|---|---|---|
| 300GB/s 未満 | 低速 | RTX 4060 |
| 300〜500GB/s | 入門〜中級 | RTX 3060、RTX 5060 Ti |
| 500〜800GB/s | 中〜上級 | RTX 4070、RTX A6000 |
| 800〜1,200GB/s | 高性能 | RTX 3090、4090、5080 |
| 1,200〜2,000GB/s | 個人・ワークステーション最上位級 | RTX 5090、RTX PRO 6000 |
| 2〜4TB/s | データセンター級 | A100・H100 系 |
| 4〜8TB/s 以上 | 最上位級 AI サーバー | H200、B200 |

## メモリバス幅の目安

| バス幅 | 格 |
|---|---|
| 64bit | 廉価・省電力向け |
| 128bit | 入門〜中級 |
| 192bit | 中級 |
| 256bit | 高性能 |
| 320〜384bit | ハイエンド |
| 512bit | 最上位級 |

## VRAM の種類

| 種類 | 主な搭載製品 |
|---|---|
| GDDR5 | 古い GeForce など |
| GDDR6 | RTX 20〜40、プロ向けの一部 |
| GDDR6X | RTX 30・40 の上位製品 |
| GDDR7 | RTX 50・RTX PRO Blackwell |
| HBM2 / HBM2e | V100・A100 など |
| HBM3 / HBM3e | H100・H200・B200 など |
| HBM4 | 新世代のデータセンター GPU |

HBM（High Bandwidth Memory）はメモリチップを積み重ねて GPU のすぐ横に置き、非常に広いバス幅（数千 bit）で接続する方式。GDDR より桁違いに帯域が広いが高価なので、データセンター向けの GPU で使われる。

## 注意点

- バス幅だけで比べない。同じバス幅でも、新しい世代の VRAM のほうが転送レートが高く、帯域が広い。
