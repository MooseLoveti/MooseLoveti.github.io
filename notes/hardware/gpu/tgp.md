## 概要

TGP（Total Graphics Power）は、グラフィックボード全体（GPU チップ・VRAM・電源回路など）が消費する電力の目安。電源ユニットの容量や冷却を選ぶときの基準になる。

| TGP | 格 |
|---|---|
| 75W 以下 | 省電力・補助電源不要級 |
| 75〜150W | 省電力な個人向け GPU |
| 150〜300W | 一般〜高性能 GPU |
| 300〜450W | ハイエンド GPU |
| 450〜600W | 最上位級 GPU |
| 700〜1,000W 級 | 高密度 AI サーバー向け |

## 注意点

- 75W 以下で「補助電源不要」になるのは、PCIe スロットから供給できる電力が最大 75W だから。それを超える GPU は、電源ユニットから補助電源ケーブルをつなぐ必要がある。
- 電源ユニットは、GPU の TGP に CPU などほかのパーツの消費電力を足して、余裕を持たせた容量を選ぶ。
