## 概要

NVIDIA の GPU には、役割の違う 2 種類の演算器が載っている。

- CUDA コア: 足し算・掛け算などの単純な計算を大量に並列で行う汎用の演算器。3D 描画や一般的な GPU 計算で使われる。
- Tensor コア: 行列の掛け算と足し算をまとめて行うことに特化した演算器。FP16 や INT8 などの低い精度で高速に計算でき、AI（ディープラーニング）の学習・推論で効く。

## CUDA コア数の目安

| CUDA コア数 | 格 | 代表的な GPU |
|---|---|---|
| 3,000 前後 | 下位 | RTX 4060 |
| 4,000〜6,000 | 中級 | RTX 5060 Ti、RTX 5070 |
| 8,000〜11,000 | 上級 | RTX 5070 Ti、RTX 5080 |
| 15,000〜18,000 | 最上位級 | RTX 4090 |
| 20,000 以上 | 大規模最上位級 | RTX 5090 |

10,000 を超えると上位クラスと考えてよい。

## 注意点

- コア 1 個あたりの性能は世代（アーキテクチャ）で変わるので、CUDA コア数を比べられるのは基本的に同じ世代の中だけ。
- AI 用途では、CUDA コア数よりも VRAM の容量やメモリ帯域が効くことが多い。
