## 用途別のシリーズ

| メーカー | シリーズ | 用途 |
|---|---|---|
| Intel | Xeon E / Xeon 6300 | 小規模サーバー |
| Intel | Xeon W / Xeon 600 | ワークステーション |
| Intel | Xeon Scalable / Xeon 6 | サーバー |
| AMD | Threadripper | 高性能デスクトップ・ワークステーション |
| AMD | Threadripper PRO | 本格的なワークステーション |
| AMD | EPYC | サーバー・データセンター |

## Xeon の型番とグレード

| シリーズ | グレード | 型番の例 |
|---|---|---|
| Xeon Scalable | Platinum | 8xxx、9xxx（例: Xeon Platinum 8368） |
| | Gold | 6xxx、5xxx（例: Xeon Gold 6348） |
| | Silver | 4xxx（例: Xeon Silver 4314） |
| | Bronze | 3xxx（例: Xeon Bronze 3204） |
| Xeon W | w3 | 例: Xeon w3-2425 |
| | w5 | 例: Xeon w5-3425 |
| | w7 | 例: Xeon w7-3445 |
| | w9 | 例: Xeon w9-3495X |

Xeon Scalable は型番の先頭の数字が大きいほど上位のグレード。Xeon W は `w3`〜`w9` の数字が大きいほど上位になる（一般向けの Core i3〜i9 と同じ感覚）。
