## 指標ごとの見方

| 指標 | 増えると | 目安 |
|---|---|---|
| 物理コア数 | 並列処理に強くなる | 6〜8 個は一般向け、16 個以上は並列作業に強い |
| クロック（GHz） | 同じ設計なら処理が速くなる | 現代のデスクトップなら最大 5GHz 超は高クロック |
| IPC | 同じクロックで処理できる命令が増える | 新しいアーキテクチャほど有利な傾向 |
| L3 キャッシュ（MB） | メモリへのアクセスを減らせる場合がある | ゲームなどで大容量が効く |
| メモリチャネル数 | CPU とメモリの間の帯域が増える | 2ch は個人向け、4〜8ch はワークステーション、12ch 級はサーバー |
| PCIe レーン数 | GPU や SSD などを多く接続できる | 20〜30 レーン級は一般 PC、80〜128 級はワークステーション |
| TDP（W） | 冷却能力・電力の要求が増える | 大きいほど高性能とは限らない |

IPC（Instructions Per Clock）は 1 クロックあたりに実行できる命令数。性能はおおよそ「クロック × IPC」で決まるので、世代の違う CPU をクロックだけで比べてはいけない。

## コア数から見た用途の目安

| 規模 | コア数の目安 | 想定用途 |
|---|---|---|
| 一般個人 | 6〜8 | Web、Office、ゲーム、プログラミング |
| 高性能個人 | 12〜16 | 仮想マシン、開発、動画編集、複数の重い作業 |
| ワークステーション | 24〜32 | CAD、コンパイル、大規模な並列処理 |
| 上位ワークステーション | 32〜96 | 大規模解析、GPU 複数枚、研究 |
| サーバー | 32〜192 以上（1 ソケットあたり） | VM の集約、データベース、大規模並列処理 |
