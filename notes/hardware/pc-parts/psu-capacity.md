| 電源容量 | 想定する構成 |
|---|---|
| 400〜550W | 省電力 PC・GPU なしの一般 PC |
| 650W | ミドルレンジ PC |
| 750〜850W | 高性能ゲーミング PC |
| 1,000W | ハイエンド PC |
| 1,200〜1,600W | 最上位 GPU 搭載機・ワークステーション |
| 1,600〜2,400W 以上 | 複数 GPU・大規模ワークステーション |
| 2,000W 級 × 2 など | 冗長電源を持つサーバー |

## 注意点

- 必要な容量は、GPU の消費電力（TGP）が大部分を占める。GPU と CPU の消費電力を合計し、そこに余裕を持たせて選ぶ。
- 冗長電源は、電源ユニットを複数載せて 1 台が壊れても動き続けられるようにする構成。合計容量ではなく、1 台で全体をまかなえる容量にするのが基本。
