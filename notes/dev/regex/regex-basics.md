正規表現でよく使う記号の早見表。

## 文字クラス

| 記号 | 意味 | 覚え方 |
|---|---|---|
| `\d` | 数字 1 文字（`[0-9]` 相当） | digit |
| `\w` | 英数字とアンダースコア 1 文字（`[A-Za-z0-9_]` 相当） | word |
| `\s` | 空白 1 文字（スペース、タブ、改行など） | space |
| `\D`、`\W`、`\S` | それぞれ小文字の逆（数字以外、など） | 大文字は否定 |
| `[abc]` | 角括弧の中のどれか 1 文字 | |
| `[a-z]` | 範囲の中のどれか 1 文字 | |
| `[^abc]` | 角括弧の中の文字**以外**の 1 文字 | 先頭の `^` は否定 |
| `.` | 改行以外の任意の 1 文字 | |

## 量指定子（直前の要素の繰り返し回数）

| 記号 | 意味 |
|---|---|
| `a*` | 0 回以上 |
| `a+` | 1 回以上 |
| `a?` | 0 回または 1 回 |
| `a{3}` | ちょうど 3 回 |
| `a{2,4}` | 2〜4 回 |
| `a{2,}` | 2 回以上 |

## アンカー（位置の指定）

| 記号 | 意味 |
|---|---|
| `^abc` | 行頭が `abc` |
| `abc$` | 行末が `abc` |

## 使用例: ログから IPv4 アドレスを重複なしで抜き出す

```
$ grep -oE '([0-9]{1,3}\.){3}[0-9]{1,3}' <logfile> | sort -u
```

- `[0-9]{1,3}\.` で「1〜3 桁の数字 + ドット」を表し、それを `{3}` で 3 回繰り返した後に最後のオクテットを続ける。
- `-o` はマッチした部分だけを出力、`-E` は拡張正規表現（`{}` や `+` をそのまま使える）。
- `.` は任意の 1 文字なので、ドットそのものにマッチさせたいときは `\.` とエスケープする。

## 注意点

- `{1,3}` だけでは `999` のような 255 を超える値も拾う。ログからの抽出なら実用上は十分だが、厳密な検証には使えない。
- `grep -E` では `\d` が使えない（GNU grep の拡張正規表現には `\d` がない）。`[0-9]` を使うか、Perl 互換の `grep -P` を使う。
- `^` は角括弧の外では「行頭」、角括弧の先頭では「否定」と意味が変わる。
