## 概要

`chroot` は change root の略で、プロセスのルートディレクトリ（`/`）を指定したディレクトリに切り替えるコマンド・システムコール。切り替えた後のプロセスからは、そのディレクトリの外のファイルが見えなくなる。

コンテナは、rootfs のディレクトリをルートに切り替えたうえで、namespace（見えるプロセスやネットワークを分ける）や cgroup（使える資源を制限する）を組み合わせて作られている。`chroot` はそのうち「ファイルシステムの見え方」だけを担当する。

## コマンド

```
$ sudo chroot <new_root> /bin/sh
```

`<new_root>` の中に実行するプログラム（ここでは `/bin/sh`）と、それが必要とするライブラリがそろっている必要がある。

## 注意点

- `chroot` 単体はセキュリティ上の隔離にはならない。中で root 権限を持つプロセスは、もう一度 `chroot` を使うなどして外に抜けられる。実際のコンテナランタイムは、抜けられにくい `pivot_root` と namespace を組み合わせて使う。
- プロセス一覧やネットワークは切り替わらないので、`chroot` の中からもホストのプロセスは見える。
